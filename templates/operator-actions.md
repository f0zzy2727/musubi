# Operator Actions

> **Pinned state surface — not a log.** This file holds only the things that
> need a decision or action from *you* (the operator) before work can proceed.
> Oya appends an item here when she needs you, and ticks it off when you've
> discharged it. If nothing is under **Pending**, nothing is waiting on you.
>
> The orchestrator watches this file and pins each outstanding ask to the tmux
> status bar (`⚑ AWAITING YOU: …`) plus fires a desktop notification on each new
> one — so a needed decision can't get buried in the pane scroll. Reply to Oya
> in her pane to discharge an item.
